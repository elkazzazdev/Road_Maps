PHASE 01 | الشهر 1 - 2
احتراف تحسين الأداء (PL/SQL & SQL Tuning)
Core Foundation

الانتقال من مرحلة "كتابة كود يعمل" إلى "تصميم كود فائق السرعة يعالج ملايين السجلات".

  • Execution Plans & AutoTrace: قراءة وتحليل خطط تنفيذ الاستعلامات ومعرفة كيفية تفادي الـ Full Table Scans.
  • Advanced Indexing Strategies: استخدام الـ B-Tree, Bitmap, و Function-Based Indexes في الأماكن الصحيحة.
  • Bulk Processing Mastery: استخدام BULK COLLECT و FORALL لتقليل الـ Context Switching بين موتور الـ SQL والـ PL/SQL.
  • Trace Tools: استخدام أدوات الـ TKPROF والـ DBMS_PROFILER لاكتشاف الاختناقات (Bottlenecks).
-- Example: Bulk Fetch with LIMIT clause for high memory efficiency
OPEN emp_cursor;
LOOP
  FETCH emp_cursor BULK COLLECT INTO l_emp_tbl LIMIT 1000;
  EXIT WHEN l_emp_tbl.COUNT = 0;
  -- Process batch efficiently
END LOOP;
PHASE 02 | الشهر 3 - 4
أدوات التقارير والبيانات في أوراكل فيوجن (Fusion Reporting Ecosystem)
Fusion Cloud
  • Fusion BI Publisher (Data Models): بناء الـ Data Models بكتابة SQL Queries متطورة مع تفعيل الـ Data Security واستخدام الـ Bursting لإرسال التقارير أوتوماتيكياً.
  • OTBI (Oracle Transactional Business Intelligence): بناء التحليلات السريعة للـ Business Users باستخدام الـ Subject Areas مع الـ Cross-Subject Analysis.
  • BICC (BI Cloud Connector): استخراج الحجم الضخم من البيانات (Bulk Extraction) بجدولة الـ PVOs للأنظمة الخارجية.
PHASE 03 | الشهر 5 - 6
أدوات الربط والتكامل (Integrations & Data Loading)
Advanced Integration
  • FBDI & HDL: تحضير رفع البيانات الضخمة في Fusion عبر ملفات الـ CSV والـ .dat للموديولات المختلفة (ERP & HCM).
  • REST & SOAP APIs: تجربة الـ Fusion Endpoints عبر Postman وكتابة أجهزة استدعاء آمنة.
  • Oracle Integration Cloud (OIC): التعرف على الـ Adapters (ERP Cloud Adapter, REST, FTP), بناء الـ Integrations (App-Driven / Scheduled), وتوجيه البيانات بـ Data Mapping.
PHASE 04 | الشهر 7 - 8
بناء التطبيقات والواجهات الحديثة (Modern UI Extensions)
Apps & UI
  • Oracle APEX & ORDS: بناء تطبيقات سريعة ومتطورة وربطها إما بـ EBS أو Fusion كـ Side-by-Side Extensions.
  • Visual Builder Studio (VBS) & Redwood: تعديل وتخصيص شاشات أوراكل الحديثة بـ Business Rules وبناء مكونات تفاعلية.
PHASE 05 | الشهر 9
الهندسة المعمارية والمهارات الإدارية (Architecture & Business)
Senior Mindset
  • Business Cycles Understanding: فهم دورات العمل الكاملة من بداية العملية الإدارية إلى شجرة الحسابات (P2P, O2C, HCM Life Cycle).
  • Technical Design Documents: كتابة وثائق التصميم المعماري مثل MD070 في EBS و TD Documents في Fusion.
  • DevOps & Source Control: حفظ وتتبع تطويرات النظام وكود الـ SQL/OIC داخل منصات **Git (GitHub/GitLab)**.

الانتقال من EBS R12 إلى Fusion Cloud
بيئة Oracle EBS R12
On-Premise
  • Database Access: وصول مباشر للجداول والـ DB Packages.
  • Integrations: DB Links, Interface Tables, Concurrent Programs.
  • Customizations: OAF Pages, Oracle Forms, PL/SQL Custom Packages.
  • Reporting: RDF Reports, BI Publisher, Discoverer.
بيئة Oracle Fusion Cloud
SaaS / Cloud
  • Database Access: لا يوجد وصول مباشر؛ التعامل عبر Data Models/APIs.
  • Integrations: REST/SOAP APIs, OIC, FBDI, HDL.
  • Customizations: Visual Builder Studio (VBS), APEX Extensions.
  • Reporting: OTBI Analysis, BI Publisher, BICC Extraction.
