Command Line Cheatsheet

دليل أهم أوامر الـ Bash والـ Terminal

مرجع سريع ومصمم بأحدث أساليب التصميم لإدارة نظام اللينكس والتيرمينال لمهندسي ومطوري البرمجيات.

إدارة الملفات والمجلدات (Files & Directories)
الأمر (Command) الوظيفة والتفاصيل
ls عرض محتويات المجلد الحالي.
استخدم ls -la لعرض التفاصيل الكاملة مع الملفات المخفية.
pwd طباعة مسار المجلد الحالي (Print Working Directory).
cd تغيير المجلد والدخول إليه.
مثال: cd Documents للدخول، أو cd .. للرجوع خطوة للخلف.
mkdir إنشاء مجلد جديد.
مثال: mkdir my_project
touch إنشاء ملف فارغ جديد.
مثال: touch script.sh
cp نسخ ملف أو مجلد.
مثال: cp file.txt /path/to/destination
mv نقل ملف أو إعادة تسميته.
مثال: mv old_name.txt new_name.txt
rm حذف ملف أو مجلد.
استخدم rm -rf folder_name لحذف مجلد بمحتوياته إجبارياً.
قراءة وعرض الملفات (Viewing & Searching)
الأمر (Command) الوظيفة والتفاصيل
cat عرض محتويات الملف بالكامل دفعة واحدة على الشاشة.
less عرض محتويات الملف بشكل صفحة صفحة (مناسب للملفات الضخمة).
head عرض أسطر الملف الأولى (الافتراضي: أول 10 أسطر).
tail عرض أسطر الملف الأخيرة.
استخدم tail -f app.log لمراقبة السجلات مباشرة في الوقت الفعلي (Live Log Feed).
grep البحث عن نص أو نمط معيان داخل الملفات.
مثال: grep -i "error" server.log
إدارة النظام والعمليات (System & Processes)
الأمر (Command) الوظيفة والتفاصيل
sudo تنفيذ الأمر بآليات وصلاحيات المسؤول الأعلى (Superuser / Root).
top / htop عرض تفاعلي مباشر للعمليات الشغالة ومعدل استهلاك الـ CPU والذاكرة.
ps عرض لقطة ثابتة من العمليات الحالية النشطة (Process Status).
kill إنهاء أو إغلاق عملية معينة باستخدام رقم التعريف الخاص بها (PID).
مثال: kill -9 1234
df -h عرض مساحات الأقراص والتخزين المتاحة والمستخدمة بشكل مقروء.
free -h عرض حجم الذاكرة العشوائية (RAM) المستخدمة والفارغة.
الشبكات والاتصال (Networking & APIs)
الأمر (Command) الوظيفة والتفاصيل
ping اختبار فحص الاتصال والتواصل بسيرفر أو عنوان معينة.
مثال: ping google.com
curl / wget إرسال طلبات الـ HTTP وتحميل الملفات مباشرة من السيرفرات والـ APIs.
ip a / ifconfig عرض تفاصيل وكروت الشبكة وعناوين الـ IP الخاصة بالجهاز.
اختصارات وأدوات مساندة
الأمر (Command) الوظيفة والتفاصيل
clear تنظيف شاشة التيرمينال مسح المخرجات السابقة (أو اختصار Ctrl + L).
history عرض سجل الأوامر الكامل التي تم تنفيذها سابقاً في التيرمينال.
man عرض الدليل والكتالوج التعليمي الكامل الخاص بأي أمر (Manual).
مثال: man grep
